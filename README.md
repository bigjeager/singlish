# Singlish

A night-mode music-app-styled single-page web app for Singlish. Built as a single self-contained `index.html` — no build step, no dependencies.

## Run locally

Just open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
